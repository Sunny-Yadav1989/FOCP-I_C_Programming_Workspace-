# FOCP-1_C_Programming_Workspace

Regular C programming work for FOCP-1.

## Structure

- `Assignment-1/` — Questions 1 to 10
- `Assignment-2/` — Questions 1 to 10

Each question is kept in a separate `.c` file so that the work is easy to compile, test, and review.

## Compile and run

Using GCC:

```bash
gcc Assignment-1/Q01_Student_Information.c -o q1
./q1
```

On Windows PowerShell, the executable can also be run with:

```powershell
gcc Assignment-1/Q01_Student_Information.c -o q1.exe
.\q1.exe
```

The programs intentionally use basic C constructs covered in introductory FOCP work: variables, input/output, arithmetic operators, if-else, switch, and simple arrays/loops where appropriate.
